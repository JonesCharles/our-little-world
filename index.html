# Decisions ## Stack chosen We chose a static HTML/CSS/JS approach to keep the experience lightweight, easy to deploy, and highly customizable for a romantic one-page interactive project. ## Why this choice - no build pipeline required - easy deployment to static hosts - perfect for a personal, atmospheric app - works well with animation, user interaction and localStorage ## Design direction The project aims to blend: - cozy indie aesthetics - pixel-inspired world building - soft magical atmosphere - romantic storytelling for Jones & Cami - playful hidden interactions and progression ## Content strategy The core narrative is centered around: - friendship through games - return and reconnection - emotional confession - joyful relationship and future together This is editable via `config.js` for quick future updates and personalization.
